Perguntas Frequentes
Como funciona o sistema de créditos?

Cada crédito XML permite baixar 1 arquivo XML completo. Os créditos são debitados automaticamente a cada download.

Os créditos expiram?

Sim, os créditos são válidos por 12 meses a partir da data da compra.

Posso combinar diferentes pacotes?

Sim, você pode comprar quantos pacotes quiser. Os créditos se acumulam no seu saldo total.

No dashboard de créditos XML você pode ver seu saldo atual, histórico de compras e relatórios de uso detalhados.
