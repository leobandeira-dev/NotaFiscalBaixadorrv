Informações do Sistema POP3
Provedores Suportados:
  • Gmail (pop.gmail.com:995)
  • Outlook (outlook.office365.com:995)
  • Yahoo (pop.mail.yahoo.com:995)
  • Servidores Personalizados
Características POP3:
  • Download completo das mensagens
  • Remove emails do servidor após download
  • Conexões SSL/TLS recomendadas
  • Isolamento por usuário
Diferenças POP3 vs IMAP:
POP3:
  • Download completo das mensagens
  • Mensagens removidas do servidor
  • Ideal para um único dispositivo
  • Menor uso de espaço no servidor
IMAP:
  • Sincronização com o servidor
  • Mensagens permanecem no servidor
  • Ideal para múltiplos dispositivos
  • Maior flexibilidade de organização
