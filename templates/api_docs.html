CROSS XML Downloader PRO API v1.0 (Speed Optimized)

API REST completa para automação de download de XMLs fiscais brasileiros com sistema de créditos integrado.

Dupla Funcionalidade: JSON + XML

A API retorna ambos os formatos para cada chave processada:

  • Dados JSON: 19 campos extraídos (número NF, valor, peso, emitente, destinatário, etc.)
  • Arquivos XML: Documentos fiscais originais completos (~4KB cada)

Dados estruturados + Arquivos originais
Recursos Principais
  • Download automático de XMLs via chaves de 44 dígitos
  • Processamento assíncrono com acompanhamento em tempo real
  • Sistema de cobrança por uso integrado (1 crédito = 1 XML)
  • Extração automática de 19 campos estruturados
  • Performance otimizada: ~7.4 segundos por XML
  • Rate limiting e controle de qualidade
  • Suporte para processamento em lote
Informações Técnicas
  • Base URL: {{ request.url_root }}api/v1
  • Formato: JSON
  • Rate Limit: 100 requisições/minuto
  • Timeout: 60 segundos
  • Encoding: UTF-8
  • HTTPS: Obrigatório
Dados Estruturados Extraídos Automaticamente

Cada XML processado retorna 19 campos estruturados prontos para uso:

NFe Básica:
  • Chave da nota fiscal (44 dígitos)
  • Número da NF e série
  • Data de emissão
  • Valor total (R$)
Transporte:
  • Peso bruto (kg)
  • Quantidade de volumes
Emitente/Remetente:
  • CNPJ e razão social
  • Cidade, UF, endereço, CEP
Destinatário:
  • CNPJ/CPF e razão social
  • Cidade, UF, endereço, CEP

Autenticação

Todas as requisições da API requerem autenticação via headers HTTP usando sua API Key.

Importante: Mantenha sua API Key segura e não a compartilhe. Ela deve ser enviada no header X-API-Key de todas as requisições.
Exemplo de Header:
X-API-Key: sua_api_key_aqui
Content-Type: application/json
Códigos de Erro de Autenticação:
Código Descrição
401 API Key não fornecida ou inválida
403 Acesso negado ou credenciais revogadas
429 Rate limit excedido

Exemplos de Código

Python
import requests
import time

API_BASE = "{{ request.url_root }}api/v1"
API_KEY = "sua_api_key_aqui"

headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
}

# Iniciar download
payload = {
    "invoice_keys": ["35250513516247000107550010000113401146202508"]
}

response = requests.post(f"{API_BASE}/jobs", json=payload, headers=headers)
result = response.json()

job_id = result["job_id"]
print(f"Download iniciado! Job ID: {job_id}")

# Aguardar conclusão
while True:
    status_response = requests.get(f"{API_BASE}/jobs/{job_id}", headers=headers)
    status = status_response.json()
    
    print(f"Status: {status['status']} - Progresso: {status.get('progress', {}).get('percentage', 0)}%")
    
    if status["status"] == "completed":
        print("Download concluído!")
        # Listar arquivos disponíveis
        files_response = requests.get(f"{API_BASE}/jobs/{job_id}/files", headers=headers)
        files_data = files_response.json()
        for file_info in files_data["files"]:
            print(f"Arquivo: {file_info['filename']}")
        break
    elif status["status"] == "failed":
        print("Download falhou!")
        break
        
    time.sleep(5)
JavaScript
const API_BASE = "{{ request.url_root }}api/v1";
const API_KEY = "sua_api_key_aqui";

const headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
};

async function downloadXML(invoiceKeys) {
    try {
        // Iniciar download
        const response = await fetch(`${API_BASE}/jobs`, {
            method: 'POST',
            headers: headers,
            body: JSON.stringify({
                invoice_keys: invoiceKeys
            })
        });
        
        const result = await response.json();
        
        console.log(`Download iniciado! Job ID: ${result.job_id}`);
        
        // Monitorar progresso
        const jobId = result.job_id;
        return await monitorJob(jobId);
    } catch (error) {
        console.error('Erro no download:', error);
    }
}

async function monitorJob(jobId) {
    while (true) {
        const response = await fetch(`${API_BASE}/jobs/${jobId}`, {
            headers: headers
        });
        
        const status = await response.json();
        const progress = status.progress?.percentage || 0;
        console.log(`Status: ${status.status} - Progresso: ${progress}%`);
        
        if (status.status === "completed") {
            console.log("Download concluído!");
            // Listar arquivos disponíveis
            const filesResponse = await fetch(`${API_BASE}/jobs/${jobId}/files`, {
                headers: headers
            });
            const filesData = await filesResponse.json();
            return filesData.files;
        } else if (status.status === "failed") {
            throw new Error("Download falhou!");
        }
        
        await new Promise(resolve => setTimeout(resolve, 5000));
    }
}

// Uso
downloadXML(["35250513516247000107550010000113401146202508"]);
